EDC Pouch User Manual
Version: 2026-06-25

============================================================
1. Overview
============================================================

EDC Pouch is a compact toolkit for Garmin watches. It combines personal utilities, calculation tools, reading and import features, small games, and system test pages in one app.

Main sections:
- Personal: Calendar, Notes, Date Counter, Tasks, Decision Wheel, Flashcards, Drawings.
- Tools: Calculator, Unit Converter, Text Reader, Date Interval, Photo Album, Solar System, Periodic Table.
- Games: 2048, Memory Match, Down 100, Gravity Surf, Basketball, 3D Maze, Gomoku, Chess, Chinese Chess.
- System: Home Style, Theme Color, Idle Clock, Haptics, Swipe Exit, Language, Lunar options, test pages, and Clear Storage.

============================================================
2. Basic Controls
============================================================

- Touch: tap menu items, buttons, cards, boards, and drawing areas.
- Swipe: used for page changes, scrolling, date changes, board movement, or view panning depending on the page.
- SELECT: confirms, starts, flips, or restarts on many pages.
- BACK: returns to the previous page. Some pages first reset zoom or view position, then exit on the second BACK.
- UP / DOWN: may change pages, zoom, move selection, or adjust values.
- MENU / long menu key: opens the current page menu.
- Swipe Exit: can be enabled or disabled in System settings. When disabled, the app tries to block accidental system right-swipe exit.

Key Nav:
- Some graph and board pages support virtual directional zones.
- Tap the outer ring to pan or zoom. Double-tap the center to switch mode.
- Double-tap the same direction to lock continuous movement. Tap anywhere to stop.
- Recently touched zones and the center circle are briefly outlined in the current theme color.

Idle Clock:
- Can be enabled in System settings.
- After the selected idle time, the app switches to a black clock screen and updates once per minute.
- Any touch or button wakes the original page.

============================================================
3. Personal
============================================================

Calendar
- Includes Gregorian month view, Lunar month view, and Day Info.
- Can show solar terms, festivals, zodiac, stems and branches, western zodiac, and almanac information.
- The Lunar option can be turned off. When off, Lunar pages and Chinese almanac calculations are hidden.
- When English is selected, Lunar display is off by default. It can still be enabled manually.
- Tap empty space in calendar or day info pages to hide text and view the background only. Tap again to restore.
- When changing month or year, the selected day is preserved when possible. If the new month does not have that day, the closest day is selected.

Notes
- Create, view, edit, and delete short notes.
- Useful for short text, lists, and temporary information.

Date Counter
- Create a title and a date.
- Future dates show days left. Past dates show days passed.
- Can be used both as countdown and day counter.
- Supports rename, change date, and delete.

Tasks
- Create tasks with optional due dates.
- Supports done, undo done, edit, and delete.

Decision Wheel
- Built-in choices include Yes/No, Yes/No/Maybe, Rock/Scissors/Paper, directions, and custom items.
- Custom items are comma-separated and have a length limit.

Flashcards
- Create decks and cards.
- Supports two-sided cards, swipe or DOWN for next card, and auto flip.
- Multiple items can be added at once with commas.

Drawings
- Drawings are stored as vector strokes, not full bitmap images.
- Pen colors and paper colors are shared with Text Reader colors.
- Toolbar includes pen color, background color, undo, eraser, clear, and done.
- Eraser removes whole strokes, not individual pixels.
- Toolbar auto-hides and can be shown by tapping.
- After each stroke, the app simplifies point data while trying to keep the shape.

============================================================
4. Tools
============================================================

Calculator
- Supports arithmetic, parentheses, functions, angle mode, repeated equals, and phone input.
- The formula demo page can be shown or hidden. When hidden, demo data is not loaded.
- Graph modes include:
  y=f(x), x=f(y), implicit equations, polar curves, parametric curves, vector fields, 3D functions, parametric surfaces, 3D ODEs, and point clouds.
- Graph examples:
  y=sin(x)
  x=sin(y+T)
  x*x+y*y=1
  r=sin(5*t+T)
  param=(sin(3*t+T),sin(4*t))
  field=(-y,x)
  z=sin(x)*cos(y)
  surface=((2+cos(v))*cos(u),(2+cos(v))*sin(u),sin(v))
  ode=(10*(y-x),x*(28-z)-y,x*y-(8/3)*z)
- Graph pages support tap selection, zoom, pan, animation, and Key Nav where available.

Unit Converter
- Supports length, area, volume, mass, speed, power, energy, temperature, pressure, computer data size, and more.
- Computer data size prioritizes commonly used binary units.
- Inverse units such as min/km show infinity at zero speed.
- 1 kWh is energy, not electric charge.

Text Reader
- Reads longer text.
- Supports font size, text color, background color, and scroll speed.
- Text can be typed from the phone or downloaded from the web.
- Search is supported. If no search term exists, SELECT shows a notice. After searching once, SELECT finds the next match.
- Font size step is 1.

Date Interval
- Calculates the difference between two dates.
- You can edit either date or edit the day count directly.
- Lunar subtitle follows the Show Lunar setting. When Lunar is off, Lunar calculation is not started.

Photo Album
- Add, download, view, and delete images.
- Supports multi-frame playback, zoom, and pan.
- After import, the content is saved. The URL itself is not stored as a permanent item.

Solar System
- Shows the Sun, Moon, and planets.
- Supports pause, time speed, jump to now, and jump to year.
- Orbit and shadow display can be toggled.

Periodic Table
- Zoom and pan the periodic table.
- Tap an element to view symbol, name, period, group, melting point, boiling point, density, atomic weight, or isotope mass.
- The element detail page shows electron shells and supports drag/tap interaction.

============================================================
5. Games
============================================================

2048
- Swipe to merge numbers.
- When the game is over or won, tap the result box or press SELECT to restart.

Memory Match
- Memorize cards, then find pairs.
- Odd card counts include a lucky card with a gold background.
- Tap the result box or press SELECT to start a new game.

Down 100
- Move downward through floors, avoid danger, and try to reach deeper floors.
- Shows reached floor and best record.

Gravity Surf
- Control a board by gravity or input.
- Rocks stop the board. Some objects spin the direction. Speed objects temporarily speed up or slow down.
- Waves make the board fly. While flying, items can still be collected but obstacles do not hit.
- Stars grant invincibility. Repeated stars extend invincibility.
- Close passes near obstacles grant a graze bonus.

Basketball
- Supports timed, free, and practice modes.
- Shows shots, made shots, and time.

3D Maze
- Supports first-person view and full map view.
- On the map, black is path and gray is wall.
- Auto explore can explore step by step and mark explored paths.
- Player path and auto exploration use different colors.
- Maze size can be changed. Best score is saved.

Gomoku
- Supports one player, two players, and CPU vs CPU.
- Board can be zoomed and dragged at any zoom level.
- BACK first resets to full view, then exits.

Chess
- Supports one player, two players, and CPU vs CPU.
- Board can be zoomed, dragged, and tapped.
- Shows turn, check, and result.

Chinese Chess
- Supports one player, two players, and CPU vs CPU.
- Board can be zoomed, dragged, and tapped.
- Shows red turn, check, and result.

============================================================
6. System Settings
============================================================

Home Style
- Choose Animated Menu or Plain Menu.
- The app does not immediately kick you out of settings. When you leave the current system menu, the home screen switches to the new style.

Theme Color
- Controls non-image UI colors such as background, text, accent, and track.
- Custom theme lets you choose colors while avoiding repeated use of the same color.

Idle Clock
- Off, 15 sec, 30 sec, 45 sec, 1 min, 2 min, or 5 min.

Haptics
- Enables or disables vibration feedback for the app.
- The sensor test page can test short, long, double, triple, and ramp vibration.

Swipe Exit
- When on, system right-swipe exit is allowed.
- When off, the app tries to block accidental swipe exit.

Language
- Traditional Chinese and English are supported.
- Inside the language menu, each language is named in itself.

Lunar Options
- Show Lunar: enables Lunar pages and Chinese almanac information.
- Lunar First: controls whether Calendar prefers Lunar view.

Default Test URL
- When enabled, text and image download forms are prefilled with test URLs.

Test Pages
- Screen Test: color bars, gray ramp, checkerboard, lines, and geometry.
- Input Event Test: shows button, touch, and back events.
- Sensor Bars Test: shows live sensor bars.
- All Sensors Test: shows available sensors, free memory, and vibration tests.
- Accel/Mag Ball Demo: uses accelerometer and magnetometer data to drive a visual demo.

Clear Storage
- Deletes local notes, tasks, reader data, drawings, photos, and settings.
- Use with care.

============================================================
7. Import and Storage
============================================================

- Text and images can be downloaded from the web.
- If downloaded content has the wrong format, parsing or saving will fail.
- After content is saved, its URL is not kept as a permanent item.
- Very large images, long text, or too much stored data may hit watch memory or storage limits.

============================================================
8. Tips
============================================================

- Disable Swipe Exit if you often leave the app by accident.
- Enable Idle Clock to reduce long-running animation when the app is left open.
- English UI does not enable Lunar by default; turn it on manually if you need traditional calendar data.
- If the UI looks unexpected, check Language, Theme Color, Lunar options, and Home Style in System settings.
