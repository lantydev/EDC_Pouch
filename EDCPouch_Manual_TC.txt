EDC Pouch 使用說明
版本：2026-06-25

============================================================
1. 簡介
============================================================

EDC Pouch 是一個 Garmin 手錶上的隨身工具包，集合個人資料、實用工具、小遊戲與系統測試功能。它支援繁體中文與英文介面，並可切換動畫首頁或普通選單首頁。

主要分類：
- 個人：萬年曆、記事、日期計數、任務、決策轉盤、閃卡、畫作。
- 工具：計算器、單位換算、閱讀、日期間隔、相簿、太陽系、元素週期表。
- 遊戲：2048、記憶翻牌、下樓100層、重力衝浪、籃球投籃、3D 迷宮、五子棋、西洋棋、中國象棋。
- 系統：首頁樣式、主題色彩、待機時鐘、震動回饋、右滑離開、語言、農曆設定、測試頁與清空儲存。

============================================================
2. 基本操作
============================================================

- 觸控：點擊項目、按鈕、棋盤、卡片或畫布。
- 滑動：在支援的頁面切換日期、翻頁、移動視角或捲動內容。
- 實體 SELECT：多數頁面用於確認、開始、翻面或重新開始。
- 實體 BACK：返回上一層。部分頁面會先重設縮放或視角，再第二次返回。
- 實體 UP / DOWN：依頁面不同，可用於翻頁、縮放、切換項目或調整數值。
- MENU / 長按選單鍵：開啟目前頁面的選單。
- 右滑離開：可在系統設定中開關。關閉時，App 會盡量阻擋系統右滑誤退出。

Key Nav：
- 部分圖形或棋盤頁面支援虛擬方向區。
- 點擊外圈可平移或縮放，雙擊中心可切換模式。
- 同一方向雙擊可鎖定連續移動，再點任意位置停止。
- 被點過的方向區與中心圓會用主題色短暫標示。

待機時鐘：
- 可在系統設定中啟用。
- 超過設定時間沒有操作時，畫面會轉為黑底時鐘，每分鐘更新一次。
- 任意按鍵或觸控可喚醒原畫面。

============================================================
3. 個人
============================================================

萬年曆
- 支援西曆月曆、農曆月曆與日資訊頁。
- 可顯示節氣、節日、生肖、干支、星座與宜忌資訊。
- 可在系統設定中關閉農曆；關閉後農曆頁、日資訊中的華人曆法資訊與相關計算都會隱藏。
- 選擇英文介面時，農曆預設關閉；之後仍可手動開啟。
- 點擊月曆或日資訊的空白區可暫時隱藏文字，只看背景；再點一次恢復。
- 切換月份或年份時，會盡量保留原本選中的日子；若新月份沒有該日，會選最接近的日期。

記事
- 可新增、檢視、編輯與刪除文字記事。
- 適合保存短句、清單、提醒或臨時資訊。

日期計數
- 可建立一個日期與標題。
- 未來日期會顯示還有幾天，過去日期會顯示已過幾天。
- 可用來記錄倒數日，也可記錄從某一天到今天已經過多久。
- 支援改名、改日期與刪除。

任務
- 可建立待辦事項，並可設定截止日期。
- 支援完成、撤銷完成、編輯與刪除。

決策轉盤
- 支援是/否、是/否/看狀況、石頭剪刀布、方位與自訂選項。
- 自訂選項以逗號分隔，每項有長度限制，適合快速做小決定。

閃卡
- 可建立牌組與卡片。
- 支援雙面翻折、滑動或 DOWN 下一張、自動翻頁。
- 可一次用逗號加入多筆內容，也可兩筆配成一張雙面卡。

畫作
- 向量方式儲存筆畫，不是存整張 bitmap。
- 可選筆色與背景色，顏色與閱讀器共用同一組色彩。
- 工具列包含筆色、背景色、復原、橡皮、清除與完成。
- 橡皮會刪除整個筆畫，而不是擦單一像素。
- 工具列會自動隱藏，點擊可喚出。
- 每次畫完一筆會整理筆畫點，盡量保留形狀並控制資料量。

============================================================
4. 工具
============================================================

計算器
- 支援一般四則、括號、函數、角度單位、重複等號與手機輸入。
- 可顯示或隱藏公式示範頁；隱藏時示範資料不會載入。
- 支援多種繪圖：
  y=f(x)、x=f(y)、隱式方程、極座標、參數曲線、向量場、3D 函數、參數曲面、3D ODE 與點雲。
- 圖形頁可點選近點、縮放、平移或使用 Key Nav 操作。

單位換算
- 支援長度、面積、體積、質量、速度、功率、能量、溫度、壓力、電腦資料大小等多類單位。
- 電腦資料大小會優先顯示常用的二進位位元單位。
- 反比單位如 min/km 會在零速度時顯示無限，而不是錯誤的小數。
- 一度電屬於能量，不是電荷。

閱讀
- 可閱讀長文本，支援字號、文字色、背景色與捲動速度。
- 可從手機輸入或網路下載文字。
- 支援搜尋字串。若尚未建立索引，SELECT 會提示先用選單搜尋；已有搜尋詞時，SELECT 可搜尋下一個。
- 字號由使用者設定，步進為 1。

日期間隔
- 可計算兩個日期之間相差幾天。
- 可直接改起訖日期，也可改天數讓另一端日期跟著變。
- 若農曆顯示開啟，會顯示對應農曆資訊；關閉時不啟動農曆計算。

相簿
- 可新增、下載、檢視與刪除圖片。
- 支援多幀圖片播放、縮放與平移。
- 下載完成後保存內容，URL 不作為永久項目保存。

太陽系
- 顯示太陽、月球與行星位置。
- 可暫停、加速時間、跳到現在或跳至指定年份。
- 可切換軌道與陰影顯示。

元素週期表
- 可縮放與拖動週期表。
- 點元素可查看符號、名稱、週期、族、熔點、沸點、密度、原子量或同位素質量。
- 詳細頁可查看電子層，並可拖動與點擊互動。

============================================================
5. 遊戲
============================================================

2048
- 滑動合併數字。
- 遊戲結束或勝利後，點結果框或按 SELECT 可重新開始。

記憶翻牌
- 先記住卡片位置，再翻出成對卡片。
- 奇數張牌會有幸運卡片，以金色背景標示。
- 結束後可點結果框或按 SELECT 開新局。

下樓100層
- 控制角色往下移動，避開危險並盡量下到更深樓層。
- 顯示抵達樓層與最佳紀錄。

重力衝浪
- 用重力或操作控制帆板滑行。
- 石頭會撞停，部分物件會讓方向旋轉，加速/減速物件會短暫改變速度。
- 浪可讓角色飛起，飛行時可吃道具但不會撞障礙；連續吃浪可延長飛行。
- 星星可進入無敵，連續吃星星可延長時間。
- 擦邊通過障礙可獲得獎勵。

籃球投籃
- 支援限時、自由與練習模式。
- 顯示投籃數、命中數與時間。

3D 迷宮
- 支援第一人稱視角與全圖地圖。
- 地圖中黑色為路，灰色為牆。
- 可自動探索，並用不同顏色標示自動探索與玩家走過的路。
- 可調整迷宮大小，並保存最高分。

五子棋
- 支援單人、雙人與電腦對電腦。
- 可縮放棋盤，任何縮放等級都能拖動與點擊。
- BACK 第一次回到全屏視角，第二次退出。

西洋棋
- 支援單人、雙人與電腦對電腦。
- 可縮放、拖動與點擊棋盤。
- 顯示回合、將軍與結果。

中國象棋
- 支援單人、雙人與電腦對電腦。
- 可縮放、拖動與點擊棋盤。
- 顯示紅方回合、將軍與結果。

============================================================
6. 系統設定
============================================================

首頁樣式
- 可選動畫選單或普通選單。
- 改完後不會立刻把使用者踢回首頁；退出目前系統選單時，首頁會自動切成新樣式。

主題色彩
- 影響 App 內非圖片美術資源的背景、文字、強調色與軌道色。
- 自訂主題可選不同顏色，避免同一顏色重複使用。

待機時鐘
- 可關閉，或設定 15 秒、30 秒、45 秒、1 分鐘、2 分鐘、5 分鐘。

震動回饋
- 可開關整個 App 的震動提示。
- 感測器測試頁可測試短震、長震、雙震、三連震與漸強震動。

右滑離開
- 開啟時允許系統右滑離開。
- 關閉時 App 會盡量攔截右滑造成的誤退出。

語言
- 支援繁體中文與 English。
- 語言選單內，每個語言項目會用該語言本身描述自己。

農曆設定
- 顯示農曆：控制農曆頁與華人曆法資訊是否啟用。
- 預設農曆：控制進入日曆時是否優先顯示農曆。

預設測試 URL
- 開啟後，文字與圖片下載頁會自動帶入測試 URL，方便體驗匯入功能。

測試工具
- 螢幕測試：色條、灰階、棋盤格、線條與幾何測試。
- 輸入事件測試：查看按鍵、觸控與返回事件。
- 感測器長條測試：查看感測器即時變化。
- 所有感測器測試：查看可用感測器、剩餘記憶體與震動測試。
- 加速度/磁力球：用加速度與磁力資料驅動畫面。

清空儲存
- 清除筆記、任務、閱讀、畫作、相簿、設定等本機資料。
- 請確認後再使用。

============================================================
7. 匯入與儲存
============================================================

- 文字與圖片可從網路下載。
- 下載內容若格式錯誤，會在解析或儲存階段失敗。
- 內容儲存後，URL 不會作為永久項目保存。
- 大型圖片、長文字或過多資料可能受手錶儲存與記憶體限制。

============================================================
8. 小建議
============================================================

- 若擔心誤滑退出，可關閉「右滑離開」，主要用實體 BACK 返回。
- 若想省電或減少長時間動畫，可開啟待機時鐘。
- 英文介面預設不載入農曆，若需要傳統曆法資訊，可在系統設定中重新開啟。
- 若 App 行為異常，可先回到首頁，再進入系統設定檢查語言、主題、農曆與首頁樣式。

EDC Pouch 使用說明
版本：2026-06-25

============================================================
1. 簡介
============================================================

EDC Pouch 是一個 Garmin 手錶上的隨身工具包，集合個人資料、實用工具、小遊戲與系統測試功能。它支援繁體中文與英文介面，並可切換動畫首頁或普通選單首頁。

主要分類：
- 個人：萬年曆、記事、日期計數、任務、決策轉盤、閃卡、畫作。
- 工具：計算器、單位換算、閱讀、日期間隔、相簿、太陽系、元素週期表。
- 遊戲：2048、記憶翻牌、下樓100層、重力衝浪、籃球投籃、3D 迷宮、五子棋、西洋棋、中國象棋。
- 系統：首頁樣式、主題色彩、待機時鐘、震動回饋、右滑離開、語言、農曆設定、測試頁與清空儲存。

============================================================
2. 基本操作
============================================================

- 觸控：點擊項目、按鈕、棋盤、卡片或畫布。
- 滑動：在支援的頁面切換日期、翻頁、移動視角或捲動內容。
- 實體 SELECT：多數頁面用於確認、開始、翻面或重新開始。
- 實體 BACK：返回上一層。部分頁面會先重設縮放或視角，再第二次返回。
- 實體 UP / DOWN：依頁面不同，可用於翻頁、縮放、切換項目或調整數值。
- MENU / 長按選單鍵：開啟目前頁面的選單。
- 右滑離開：可在系統設定中開關。關閉時，App 會盡量阻擋系統右滑誤退出。

Key Nav：
- 部分圖形或棋盤頁面支援虛擬方向區。
- 點擊外圈可平移或縮放，雙擊中心可切換模式。
- 同一方向雙擊可鎖定連續移動，再點任意位置停止。
- 被點過的方向區與中心圓會用主題色短暫標示。

待機時鐘：
- 可在系統設定中啟用。
- 超過設定時間沒有操作時，畫面會轉為黑底時鐘，每分鐘更新一次。
- 任意按鍵或觸控可喚醒原畫面。

- 感測器測試頁可測試短震、長震、雙震、三連震與漸強震動。

右滑離開
- 開啟時允許系統右滑離開。
- 關閉時 App 會盡量攔截右滑造成的誤退出。

語言
- 支援繁體中文與 English。
- 語言選單內，每個語言項目會用該語言本身描述自己。

農曆設定
- 顯示農曆：控制農曆頁與華人曆法資訊是否啟用。
- 預設農曆：控制進入日曆時是否優先顯示農曆。

預設測試 URL
- 開啟後，文字與圖片下載頁會自動帶入測試 URL，方便體驗匯入功能。

測試工具
- 螢幕測試：色條、灰階、棋盤格、線條與幾何測試。
- 輸入事件測試：查看按鍵、觸控與返回事件。
- 感測器長條測試：查看感測器即時變化。
- 所有感測器測試：查看可用感測器、剩餘記憶體與震動測試。
- 加速度/磁力球：用加速度與磁力資料驅動畫面。

清空儲存
- 清除筆記、任務、閱讀、畫作、相簿、設定等本機資料。
- 請確認後再使用。

============================================================
7. 匯入與儲存
============================================================

- 文字與圖片可從網路下載。
- 下載內容若格式錯誤，會在解析或儲存階段失敗。
- 內容儲存後，URL 不會作為永久項目保存。
- 大型圖片、長文字或過多資料可能受手錶儲存與記憶體限制。

============================================================
8. 小建議
============================================================

- 若擔心誤滑退出，可關閉「右滑離開」，主要用實體 BACK 返回。
- 若想省電或減少長時間動畫，可開啟待機時鐘。
- 英文介面預設不載入農曆，若需要傳統曆法資訊，可在系統設定中重新開啟。
- 若 App 行為異常，可先回到首頁，再進入系統設定檢查語言、主題、農曆與首頁樣式。
