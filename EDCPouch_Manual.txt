English Manual
============================================================

1. Overview
EDC Pouch is a compact toolkit for Garmin watches. It combines calendar tools, reading, calculation, conversion, photos, games, sensors, and small daily utilities in one app.

Main modules:
- Calendar: Gregorian calendar, lunar calendar, day details, date interval, countdown.
- Personal tools: tasks, notes, drawing.
- Reading and import: text reader, photo album, network download.
- Tools: calculator, unit converter, decision wheel, solar system, periodic table, flash cards.
- Games: 2048, Down 100 Floors, Gravity Surf, Basketball, Memory, 3D Maze, Gomoku, Chess, Chinese Chess.
- System: about, sensors, screen test, input event test, settings, exit app.

2. Basic Controls
- Touch: tap items, buttons, and screen regions.
- Swipe: used by pages that support page switching, movement, date switching, board moves, or panning.
- Physical Back: returns to the previous page. Many pages prefer physical Back to avoid accidental swipe exit.
- Long Up / Menu: opens the current page menu.
- Physical Up / Down: often used for page up/down, zoom, menu movement, or value changes.
- Swipe exit: controlled in system settings. When disabled, the app tries to block accidental system right-swipe exit.

3. System Settings
Common settings:
- Show Lunar: enable lunar calendar, solar terms, festivals, and Chinese almanac information.
- Default Lunar: prefer lunar calendar pages. If Show Lunar is off, enabling this also turns Show Lunar on.
- Default Test URL: prefill test URLs in text and photo download pages.
- Swipe Exit: let the system handle right-swipe exit when enabled.
- Exit App: fully close the app.
- Clear Storage: clear user data after confirmation.

4. Calendar
Gregorian page:
- Shows month, year, weekday row, and dates.
- Supports month/year switching.
- Background can follow date-related themes such as zodiac or solar terms.

Lunar page:
- Shows lunar month/day, solar terms, festivals, and almanac information.
- If Show Lunar is disabled, this page and related calculations are hidden.

Day details:
- Shows Gregorian date, lunar date, solar term, festival, Chinese zodiac, western zodiac, and almanac info.
- Tap empty space to hide text and view only the background. Tap again to restore.

Date picker:
- Supports Gregorian and lunar picking.
- When switching month/year, the selected day number is preserved when possible. If not available, the closest day is selected.

Date interval:
- Shows the difference between two dates.
- Can edit dates or edit day count directly.
- Lunar subtitle follows the Show Lunar setting.

5. Countdown, Tasks, Notes
Countdown:
- Add a target date and title.
- Shows days remaining or days passed.
- Detail page supports edit, jump to today, and delete.

Tasks:
- Add, edit, complete, and delete tasks.
- Deadline is supported.

Notes:
- Add and edit short text notes.

6. Drawing
Drawing is vector-based, not bitmap storage.

Controls:
- Drag to draw strokes.
- Toolbar includes pen color, background color, undo, eraser, delete, and done.
- Toolbar auto-hides and can be shown by tapping.
- Eraser deletes whole strokes instead of doing pixel erase.

Performance:
- Points are sampled while drawing.
- After each stroke, the app simplifies the stroke while trying to keep the shape.
- If finishing while a stroke is still being processed, a progress indicator is shown.
- Last pen color and background color are remembered.

7. Text Reader
Text Reader is for longer text.

Controls:
- Swipe or use physical keys to scroll/page.
- Global font size, text color, background color, and scroll speed can be adjusted.
- When using nav key lock/scroll, page number and green info appear briefly and then disappear.

Import:
- Text can be entered from the phone or downloaded from the network.
- If Default Test URL is enabled, the download page is prefilled.

8. Photo Album
Photo Album imports and displays images or animated frames.

Features:
- Download image data.
- Play multi-frame images.
- Zoom, pan, and switch images.
- Menu supports rename and delete.

Import:
- Default Test URL can prefill the download field.
- After import, the content is saved. The URL itself is not kept as a permanent item.

9. Calculator
The calculator supports normal calculation, repeated equals, phone input, and graphing.

Normal calculation:
- Enter an expression and press Solve/equal.
- Repeated equals repeats the previous operation, such as 2*2 -> 4 -> 8.

Phone input:
- Use the calculator menu to enter complex formulas from the phone.

Demo page:
- The calculator menu has a Demo Page toggle.
- When disabled, the demo page is hidden and the demo XML is not loaded.

Graph syntax:
- Graph expressions should be explicit.
- If the expression is an equation, it is handled as an equation.
- If it is not an equation, use a clear prefix such as y=, x=, param=, r=, field=, z=, surface=, ode=, or points=.

Variables:
- x, y, z are coordinate variables.
- t, u, v are scan parameters in modes that use them.
- T is animation time.

Supported graph modes:
- y=f(x): y=sin(x)
- x=f(y): x=sin(y+T)
- Implicit equation: x*x+y*y=1
- Parametric curve: param=(sin(3*t+T),sin(4*t))
- Polar: r=sin(5*t+T)
- Vector field: field=(-y,x)
- 3D function: z=sin(x)*cos(y)
- Parametric surface: surface=((2+cos(v))*cos(u),(2+cos(v))*sin(u),sin(v))
- 3D ODE: ode=(10*(y-x),x*(28-z)-y,x*y-(8/3)*z)
- Points: points=((0,0),(1,1),(2,0)) or 3D points.

Graph controls:
- Tap to select the nearest point.
- In animation, a selected point can stay centered while the view follows it.
- Back exits selection, resumes animation, resets view, or returns depending on state.
- 2D plots support pan and zoom with equal x/y scale.

10. Unit Converter
Supports common units such as length, area, volume, mass, speed, power, energy, and temperature.

Notes:
- Pace such as min/km is inverse speed. At zero speed, pace should be infinity, not a tiny scientific value.
- 1 kWh is energy, not electric charge.
- Boiler horsepower is different from ordinary horsepower.

11. Decision Wheel
Randomly picks from custom options.

Features:
- Custom options are supported.
- Option count and text length are limited.
- Final result is shown fully when possible.

12. Solar System
Shows a simplified solar system.

Features:
- Jump to current time.
- Change year.
- Show or hide orbits.
- Shadows are off by default.
- Touch zones scale with screen size.

13. Periodic Table
Shows element information.

Features:
- Browse the table.
- Tap an element for details.
- Detail page shows symbol, name, atomic number, mass, category, and other data.
- Element data is loaded when entering the module and cleared when leaving.

14. Flash Cards
Simple memory cards.

Features:
- Create decks and cards.
- Single-side and two-side modes.
- Flip, next, and previous are supported.
- Long text is limited to avoid layout problems.

15. Games
2048:
- Swipe to move tiles.
- Merge up to 2048 or higher.

Down 100 Floors:
- Move the character downward while avoiding danger.

Gravity Surf:
- Control with motion and touch.

Basketball:
- Control shot direction and power.

Memory:
- Flip cards and match pairs.
- Odd grids include one lucky card. It has a golden background and completes when flipped.

3D Maze:
- Supports first-person and map views.
- On the map, black is path and gray is wall. The outer border is also wall.
- Auto explore can walk step by step.
- User path and auto-explore path use different colors.
- Restart after winning asks for confirmation.

Board games:
- Gomoku, Chess, and Chinese Chess provide board interaction and piece movement.

16. System Tests
Sensor tests:
- Show available accelerometer, magnetometer, pressure, heart rate, and other sensor data.

Screen test:
- Check colors and screen area.

Input event test:
- Shows touch, swipe, drag, physical key, and other events.
- Useful for comparing real device and simulator behavior.

17. FAQ
Q: Why does right swipe not exit on some pages?
A: To avoid accidental exits on gesture-heavy pages. Use physical Back, or enable Swipe Exit in settings.

Q: Why do lunar details disappear when Show Lunar is off?
A: This is intentional. Lunar calculation and resources are skipped to reduce memory and processing.

Q: Why is the download URL not saved?
A: The URL is only an import source. The imported content is what should be saved.

Q: Why does drawing show processing?
A: Long strokes are simplified in small batches to avoid watchdog crashes.

Q: Why are both T and t used in calculator graphs?
A: T is animation time. t is a scan parameter for parametric or polar modes. Use the full syntax for the selected mode.

1. 应用简介
EDC Pouch 是一个 Garmin 手表上的小工具合集。它不是一个单一功能应用，而是把日历、阅读、计算、单位换算、图片、游戏、传感器测试和一些日常记录工具放在一起，方便随手使用。

主要模块：
- 日历：西历、农历、日期详情、日期间隔、倒数日。
- 记录：任务、笔记、画画。
- 阅读与导入：文本阅读、图片相册、网络下载。
- 工具：计算器、单位转换、决策盘、太阳系、元素周期表、闪卡。
- 游戏：2048、下100层、重力冲浪、篮球、记忆、3D迷宫、五子棋、国际象棋、中国象棋。
- 系统：关于、传感器、屏幕测试、输入事件测试、设置和退出。

2. 基本操作
- 触摸：点击项目、按钮或屏幕区域。
- 滑动：在支持滑动的页面用于翻页、移动、切换日期、移动棋子或平移视图。
- 物理 Back：返回上一级。很多页面把退出交给物理 Back，避免误滑退出。
- 长按 Up / Menu：打开当前页面菜单。
- Up / Down 物理键：常用于上一页/下一页、缩放、菜单移动或数值调整，具体按页面而定。
- 右滑退出：系统菜单里有开关。关闭时尽量避免系统右滑误退出；打开时右滑交给系统处理。

3. 系统菜单
系统菜单里常用选项：
- 显示农历：控制日历是否加载和显示农历、节气、宜忌等华人历法信息。
- 默认农历：打开后日历优先显示农历相关页面；如果农历显示是关闭的，点这个会自动打开农历显示。
- 默认测试URL：打开后，文本下载和图片下载会自动填入测试 URL，方便体验导入流程。
- 右滑退出：控制系统右滑退出行为。
- 退出 App：彻底关闭应用。
- 清空存储：清空用户数据，操作前会确认。

4. 日历
日历包含西历页、农历页、日期详情和日期选择。

西历页：
- 显示月份、年份、周视图和日期。
- 支持切换月份和年份。
- 背景会根据日期显示相关图片，例如星座、节气等。

农历页：
- 显示农历月、农历日、节气、节日和宜忌。
- 如果系统设置中关闭“显示农历”，这个页面和相关信息不会显示，也不会启动农历计算。

日期详情：
- 展示当前日期的西历、农历、节气、节日、生肖、星座、宜忌等信息。
- 点击空白区域可以隐藏文字，只看背景；再次点击恢复。

日期选择：
- 支持西历/农历选择。
- 切换年月时，会尽量保持当前选中的日号；如果新月份没有这一天，会选择最接近的日期。

日期间隔：
- 显示两个日期之间的差值。
- 支持按日期或按天数调整。
- 当农历显示关闭时，不显示农历副标题。

5. 倒数日、任务、笔记
倒数日：
- 添加一个日期和标题后，显示距离目标日还有多少天或已经过了多少天。
- 详情页可编辑、跳到今天或删除。

任务：
- 可添加、编辑、完成、删除任务。
- 支持截止日期。

笔记：
- 可添加、编辑标题和正文。
- 适合短文本记录。

6. 画画
画画是矢量存储，不是保存整张位图。

操作：
- 拖动画线。
- 工具栏包含画笔色、背景色、撤销、橡皮、删除、完成。
- 工具栏会自动隐藏，点击可唤出。
- 橡皮是整笔擦除，不做复杂像素擦除。

性能与存储：
- 画的时候会实时采样。
- 松手后会整理笔画，尽量保留形状并减少点数。
- 如果按完成或返回时仍在整理，会显示进度。
- 画笔色和背景色会记住上次选择。

建议：
- 很长、很密的线会需要整理时间。
- 如果想画圆，尽量慢一点、连续一点，避免快速抖动造成过多点。

7. 文本阅读
文本阅读用于看较长文本。

操作：
- 上下滑或物理键翻页/滚动。
- 可设置全局字体大小、文字颜色、背景颜色和滚动速度。
- Nav key 锁定/滑动时，页码和绿色信息会短暂显示后自动消失。

导入：
- 可以从手机输入或从网络下载文本。
- 如果系统菜单打开“默认测试URL”，下载页面会自动填入测试 URL。

8. 图片相册
图片相册用于导入和查看图片或 GIF。

功能：
- 可下载图片数据。
- 可播放多帧图片。
- 可缩放、平移、切换图片。
- 菜单里可改名或删除。

导入：
- 如果系统菜单打开“默认测试URL”，图片下载会自动填入测试 URL。
- 下载成功后保留内容，不需要长期保存 URL。

9. 计算器
计算器支持普通计算、连续等号、手机输入和多种绘图。

普通计算：
- 输入表达式后按 Solve/等号求值。
- 连续按等号会重复上一次操作，例如输入 2*2 得到 4，再按一次可继续得到 8。

手机输入：
- 计算器菜单里可选择手机输入。
- 适合输入复杂公式。

Demo 页：
- 计算器菜单里有 Demo 页开关。
- 关闭后不显示 Demo 页，也不加载 demo XML。

绘图规则：
- 绘图表达式尽量写完整，不靠猜。
- 如果表达式本身是等式，按等式处理。
- 如果不是等式，需要带明确前缀，例如 y=、x=、param=、r=、field=、z=、surface=、ode=、points=。

变量约定：
- x, y, z 是坐标变量。
- t, u, v 是扫描参数，只在对应模式中使用。
- T 是动画时间，用于让图形随时间变化。

支持的绘图模式：
- y=f(x)：二维显函数，例如 y=sin(x)。
- x=f(y)：横向显函数，例如 x=sin(y+T)。
- 隐式方程：例如 x*x+y*y=1。
- 参数曲线：param=(sin(3*t+T),sin(4*t))。
- 极坐标：r=sin(5*t+T)。
- 向量场：field=(-y,x)。
- 三维函数：z=sin(x)*cos(y)。
- 参数曲面：surface=((2+cos(v))*cos(u),(2+cos(v))*sin(u),sin(v))。
- 三维 ODE：ode=(10*(y-x),x*(28-z)-y,x*y-(8/3)*z)。
- 点集：points=((0,0),(1,1),(2,0)) 或三维点。

绘图操作：
- 点击选择最近点。
- 动画中选点后，视图可跟随选中点。
- Back 可退出选点/恢复动画/返回页面，具体按图形状态决定。
- 2D 绘图支持平移和缩放，尽量保持 x/y 等比例。

10. 单位转换
支持长度、面积、体积、质量、速度、功率、能量、温度等常用单位。

注意：
- 配速 min/km 是速度的反比单位。速度为 0 时，配速应显示为无限，而不是极小科学计数。
- “一度电”是能量单位，即 1 kWh，不是电荷单位。
- 锅炉马力和普通马力不是同一个单位，已按锅炉马力处理。

11. 决策盘
用于随机选择一个选项。

功能：
- 可自定义选项。
- 自定义选项有数量和长度上限。
- 结果会完整显示，避免只看到截断文本。

- 阴影默认关闭。

13. 元素周期表

功能：
- 可浏览元素表。

- 详情展示符号、名称、原子序数、质量、分类和其他数据。

14. 闪卡
用于简单记忆卡片。

功能：
- 可创建卡组和卡片。
- 支持单面/双面模式。
- 可翻卡、上一张、下一张。
- 文本过长会做限制，避免布局崩。

15. 游戏
2048：
- 滑动移动方块。
- 合成到 2048 或更高分。

下100层：
- 控制角色下降，避开危险。

重力冲浪：

棋类：

17. 常见问题
Q: 为什么有些页面右滑不会退出？
A: 为了避免手势页面误退出。请用物理 Back 返回，或在系统菜单打开右滑退出。

Q: 为什么关闭农历后有些信息消失？
A: 这是设计。关闭后不加载农历、节气、宜忌等内容，以减少计算和内存占用。

Q: 为什么下载 URL 不保存？
A: URL 只是导入入口。内容下载成功后保存内容本身，URL 不需要长期保留。

Q: 为什么画画完成时会显示整理？
A: 手表性能有限，长笔画需要分帧压缩，避免 watchdog 和卡死。

Q: 为什么计算器有 T 和 t？
A: T 是动画时间。t 是曲线或极坐标等模式里的扫描参数。不要混用；按绘图模式写完整表达式。
